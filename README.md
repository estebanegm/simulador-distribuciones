# Simulador de Distribuciones de Probabilidad

App interactiva para generar datos aleatorios de distribuciones Normal, t de Student y F de Fisher.

## Características
- Selección interactiva de distribución
- Ajuste de parámetros en tiempo real
- Visualización de histograma vs densidad teórica
- Cálculo automático de media y desviación estándar
